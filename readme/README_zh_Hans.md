# BilibiliReminder

订阅 B 站 UP 主的开播状态，开播时在聊天里主动提醒你的 LangBot 插件。

适配 LangBot 4.x 插件系统。在 [Hanschase/BreminderPlugin](https://github.com/Hanschase/BreminderPlugin) 的基础上修改而来。

## 功能

- 按房间号订阅任意 B 站直播间，支持短号，也可以直接粘贴直播间链接。
- 群聊、私聊都能用。群聊里开播提醒会 `@` 所有订阅了这个直播间的人。
- 订阅按人记录，同一个群里每个人维护自己的订阅列表。
- 每轮轮询把所有直播间合并成批量请求，订阅再多也不会成倍增加请求量。
- 订阅数据保存在 LangBot 的插件持久化存储中，与当前安装和工作区绑定。

## 安装

在 LangBot 的插件市场安装，或参考[插件安装说明](https://langbot.app/docs/zh/plugin/plugin-intro)。

## 使用

所有功能都是 `sb` 命令的子命令（`!` 为默认命令前缀）：

| 命令 | 说明 |
| --- | --- |
| `!sb` | 查看用法 |
| `!sb sub <房间号>` | 订阅直播间 |
| `!sb unsub <房间号>` | 取消订阅 |
| `!sb rooms` | 查看自己在当前会话订阅了哪些直播间 |
| `!sb status` | 查看自己订阅的直播间当前的开播状态 |

例如：`!sb sub 21452505`

插件加载后会自动开始轮询，不需要再发命令启动。

## 配置项

在 LangBot 的插件管理页面配置：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 查询间隔（秒） | `60` | 轮询直播间状态的间隔，小于 15 秒会被强制为 15 秒。 |
| 兜底封面图 | 空 | UP 主没设置直播间封面时，提醒消息里使用的图片。留空则提醒消息只发文字，不附图片。 |
| 出错时通知管理员 | `false` | 推送开播提醒失败时私聊通知管理员。 |
| 管理员账号 ID | 空 | 接收异常通知的账号 ID，例如管理员 QQ 号。 |

## 从 0.1.x 升级

0.2.0 适配的是 LangBot 4.x 插件系统，与旧版数据不兼容：

- 命令变了：`!apply` / `!cancel` / `!rooms` / `!startrem` 换成 `!sb sub` / `!sb unsub` / `!sb rooms`，轮询任务改为自动启动。
- 订阅数据不再写 `subscription.json`，旧文件不会被导入，需要重新订阅一次。

## 说明

- 插件只读取 B 站公开的直播间信息，不需要登录 B 站账号。
